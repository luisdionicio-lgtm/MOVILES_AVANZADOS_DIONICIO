# Laboratorio 06 - UIKit y navegación

Los proyectos del laboratorio están organizados en esta carpeta:

- `Manual/Semana06_01_Navegacion`: Navigation Controller y segue Show entre dos pantallas.
- `Manual/Semana06_02`: ingreso de datos del cliente y presentación modal.
- `AI_Assisted/Semana06_04_VentaPlazos`: calculadora de venta a plazos con `VentaModel` y segue `showResultado`.

## Ejecución

1. Abre el archivo `.xcodeproj` del ejercicio.
2. Selecciona **iPhone 17 Pro - iOS 26.5**.
3. Ejecuta con `Cmd + R`.

No se requieren paquetes ni dependencias externas. Los proyectos usan únicamente UIKit y Foundation incluidos en Xcode.
