# Requerimientos funcionales

## Actividad 01: Matrícula de cursos

- Registrar los datos del estudiante: nombre, DNI y condición de alumno Tecsup.
- Agregar cursos indicando nombre, precio unitario y cantidad.
- Calcular el importe de cada curso, el subtotal, el IGV del 18 % y el total con IGV.
- Aplicar un descuento del 10 % cuando se registren tres o más cursos.
- Aplicar un descuento adicional de S/ 400 cuando el estudiante sea alumno Tecsup y registre tres o más cursos.
- Mostrar una factura con el detalle de los cursos, impuestos, descuentos y total final en soles.

## Actividad 02: Gestión de clientes

- Registrar los datos comunes del cliente: código, dirección, fecha de registro, número de cuenta y monto mínimo de apertura.
- Registrar clientes naturales con nombre completo y DNI.
- Registrar clientes jurídicos con razón social, RUC y representante legal.
- Utilizar herencia para compartir los datos comunes y polimorfismo para mostrar la información según el tipo de cliente.
- Almacenar y listar clientes naturales y jurídicos en una misma colección, mostrando sus datos completos y montos en soles.
