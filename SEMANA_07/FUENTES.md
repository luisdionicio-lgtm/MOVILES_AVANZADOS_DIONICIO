# Fuentes de las culturas e imágenes

Las descripciones se redactaron de forma breve para el caso educativo, tomando como referencia las fichas de patrimonio de UNESCO:

- [Santuario histórico de Machu Picchu](https://whc.unesco.org/en/list/274/).
- [Líneas y geoglifos de Nasca y Palpa](https://whc.unesco.org/en/list/700/).
- [Sitio arqueológico de Chavín](https://whc.unesco.org/en/list/330/).
